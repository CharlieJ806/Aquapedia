# 水族百科 · Aquapedia

本地离线的水族百科 + 行情参考应用。整合 **Seriously Fish**（1804 篇物种饲养档案）与
**LiveAquaria**（2944 条在售商品/报价），补充**百度百科中文名**与**人民币换算价格**。

## 运行

```bash
python serve.py
# 打开 http://127.0.0.1:8790
```

纯静态前端，无构建步骤。图片（360MB）已全部本地化到 `app/img/`。

## 功能

- **物种档案 / 物品档案 / 模拟鱼缸** 三 Tab。物种卡主标题为中文名（学名斜体副行）；**物品档案 = LiveAquaria 器材+饲料商品**（带图 + 人民币价格），过滤「全部 / 器材/设备 / 饲料」；物种类型过滤不含器材/饲料
- 搜索：支持**中文名**（含百科别名）、学名、英文俗名、异名，如「斗鱼」「灯鱼」「Betta」「Apistogramma」
- 筛选：水域（淡水/汽水/海水）、类别、水温区间、pH 上限、最大体长、**价格上限（¥）**、有图/有价
- 排序：**热度 ↓**、体长、水温、价格（升/降）；详情弹窗含饲养参数、分布/栖息/食性/混养/繁殖等章节
- **收藏**：卡片/详情弹窗的 ★ 可收藏（localStorage 持久化，刷新保留），工具栏「只看收藏」一键筛选。
- **响应式 / 双端**：桌面自适应多列栅格；≤768px 手机端**底部导航栏**、**筛选折叠成「筛选」按钮**（点开显示全部筛选项）、搜索/下拉全宽、栅格 2 列、弹窗近全屏；≤320px 单列。

## 数据口径

| 字段 | 说明 |
| --- | --- |
| `name_zh` / `zh_aliases` | 百度百科中文名（含俗称/别名），仅在词条页验证到拉丁学名后才采信；查不到即留英文，不造译名 |
| `price` | **人民币**：`min`/`max`（CNY，整数）；按固定近似汇率 7.2 从美元价换算（大致范围，非每日精准汇率） |
| `price_usd` | 原始美元价，供核对 |

当前中文名覆盖：**物种 1263/1263（100%），有图 1216/1263**（SF/LiveAquaria 图 + iNaturalist 照片兜底），在售商品 **836/2975（28.1%）**。图鉴只保留**至少有中文数据源**的物种（百度百科/iNaturalist 中文名），无中文名的 SF 冷门鱼已剔除（保留英文原文于商品侧供识别）。每个物种带**哔哩哔哩热度分**（`heat`，可「按热度↓」排序、卡片显示「热度 X万」；鱼与非鱼均按热度选）。
色系变种多且热门的物种（新米虾/水晶虾/孔雀鱼/斗鱼）在详情弹窗含**「色系变种」**区（变种名+简介+图），变种名可直接搜索命中（如「极火虾」「红白水晶虾」「礼服孔雀鱼」）。

## 数据来源与管道

```text
scrape/sf.py    → data/raw/sf.jsonl + app/img/sf/    # Seriously Fish 档案+图片
scrape/la.py    → data/raw/la.json + app/img/la/     # LiveAquaria 商品+价格(USD)+页缓存
scrape/zh_harvest*.js  → data/raw/zh*.jsonl          # 百度百科：浏览器同源抓取（含断点续传）
scrape/zh_inat.py      → data/raw/zh_inat.jsonl     # iNaturalist：学名→中文名（免费API、无反爬、简→繁转简体）
scrape/bili_heat.js    → data/raw/bili_heat.jsonl     # 哔哩哔哩水族内容热度（中文平台选种：按播放量排物种热度）
scrape/zh_baike_hot.js → data/raw/zh_baike_hot.jsonl  # 热门缺失物种：百度百科中文名+正文（按中文关键词同源抓取）
scrape/inat_img.py     → data/raw/inat_img.json      # iNaturalist 照片兜底：无图物种补图（本地化到 app/img/inat/）
data/build_zh.py       → data/raw/zh.json           # 中文名去噪汇总（多源合并+泛称过滤，merge 的输入）
data/merge.py          → app/data/species.json     # 合并/清洗/换汇 → 前端数据包
```

- 学名匹配：拉丁学名归一化精确匹配，英文俗名兜底；LA 独有商品进 `products`
- 清洗：华氏残留修复（`fix_temps`）、作者引证拆分（`split_author`）、slug 重建兜底
- 物种正文保持 Seriously Fish 英文原貌（1804 篇不翻译），中文名仅作标题/检索增强
- **热门物种扩充**：以哔哩哔哩（中国视频平台）水族内容播放量为热度信号，挑出图鉴缺失的热门物种
  （金鱼、锦鲤、斑马鱼、小丑鱼、黄金吊、六角恐龙、水晶虾/大和藻虾、水榕/椒草/莫斯/水草、螺等），
  中文名+正文取百度百科（`zh_baike_hot.js`），作为独立物种并入（`nf:` 前缀）。选种基准已采纳
  哔哩哔哩热度；淘宝/京东真实购买热度因触发账号风控（京东风控验证页）未批量采集，如需可人工核实。

## 中文名抓取说明（zh_harvest）

百度百科对脚本流量有反爬，纯 requests 会 403，故用真实 Chromium：
在百科页面上下文同源 `fetch`（继承浏览器 TLS/会话），三层策略——
1. `/item/{学名}` 直连（词条配拉丁别名时重定向直达）
2. 站内搜索页富卡片摘要（含「俗称/别名/学名」）
3. 搜索页薄卡片 → 逐个抓词条页验证拉丁学名

每层都要求**词条页面/摘要中出现目标拉丁学名**才采信标题为中文名。
礼貌抓取：单标签 ≤2 并发、0.3–0.7s 间隔、jsonl 逐条落盘断点续传。
反爬触发会返回「百度安全验证」页，收割器检测到即停，冷却后可重跑（已抓记录自动跳过）。
百度封锁期间改用 iNaturalist（学名→中文名的权威 API，无浏览器反爬；仅在返回的物种名与学名严格一致时采信，
并转成简体字）。两路名称都经 `data/build_zh.py` 去噪汇总：剔除科/属共性泛称（如「迷鳃鱼类」），
只在词条/物种与拉丁学名对应时才采信。
